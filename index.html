AI lineup analyst

Reads live news across the web — injury reports, beat-writer updates, snap-count/role trends, weather, Vegas lines, and expert start/sit consensus (FantasyPros, ESPN, PFF, etc.) — not just Sleeper's static projections, and reasons through the close calls on your full roster (starters + bench) to recommend a lineup. Uses the same Anthropic API key as "Ask about your lineup" below, so set that up first if you haven't. Each run does real web research, so it costs a bit more than a single chat question and can take up to a minute.

Ask about your lineup

This calls the real Anthropic API directly from your browser, using your own API key — so answers can do live web research beyond just Sleeper's data. Two things worth knowing: your key is stored only in this browser (never uploaded to GitHub or included in "Export settings"), and each question uses your own Anthropic account, so it isn't free.

Free agent suggestions

Ranked across all positions by value over replacement (not split into position buckets), weighted by how badly you actually need that position right now, with a verdict so it's clear what to actually do: Add now (a real upgrade over your weakest rostered player there — drop target included), Streamer (matchup-driven DST/K play, not a long-term hold), Stash (worth a bench spot — projects well, trending on the waiver wire, or the market sees real season-long upside even if this week's number is modest), or Watch (on your board but no strong signal yet). A 📈 badge means the market's season-long position ranking sees more in them than this week's projection alone shows. Double-click any player for an on-demand deep dive — a live web search for recent news on that specific player, combined with our internal read, ending in a verdict.

Trade suggestions

The 2-3 strongest trade pitches across your whole league right now — scanned against every other roster, scored on real season-long market value (not a stale board or raw depth counts) for both fairness and how much it actually fills a need on each side. Realistic starting points to take to a manager, not final offers — you'll still need to negotiate.
